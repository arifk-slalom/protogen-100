# Arif — Designer

Personal portfolio site for Arif, a designer working across identity, editorial, and digital projects.

## Structure

- [index.html](index.html) — page markup
- [styles.css](styles.css) — all styling
- [app.js](app.js) — theme toggle, mobile nav, scroll reveal, header/scroll progress, project cursor, footer year, and the weather widget (geolocation + [Open-Meteo](https://open-meteo.com/))

## Running locally

Static site, no build step. Serve the directory with any static file server, e.g.:

```
python3 -m http.server 8000
```

then open `http://localhost:8000`.
